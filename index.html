TENTANG KELAS

Keluarga Besar XI TKJ 1

Mengenal lebih dekat identitas, pilar keahlian, dan komitmen para calon network engineer dan developer SMKN 1 Kras.

Computer Networking

Mengkaji arsitektur jaringan komputer, konfigurasi switch/router, routing dinamis (OSPF/BGP), subnetting VLSM, dan instalasi serat optik.

Programming & Web

Membangun keterampilan pemrograman, logika algoritma, pembuatan aplikasi website, otomatisasi skrip, serta integrasi API.

Cyber & System Admin

Mengelola sistem operasi Linux Debian, DNS server, Web server Apache/Nginx, firewall MikroTik, dan pemeliharaan keamanan infrastruktur siber.
